About

動かしてみないと腑に落ちない性格なので、理解したいものは作ってしまうことにしています。スパゲッティブリッジのような授業の実験をシミュレーションとスコアで再現したり、RISC-V エミュレータで OS を動かしてみたり、レジスタやページテーブルを読み解く道具を作ったり。

作ったものはなるべくブラウザで動く形にして、インストール不要で誰でも触れるようにしています。以前はマイクロマウスや倒立振子、環境モニタなどの電子工作もしていて、その記録はブログに残しています。

sim_game

物理の直感を作るシミュレーションゲーム集。ハイスコアを狙って何度も試行錯誤するうちに、物理の感覚が身につきます。

  • Bridge Lab材料を節約して重い荷重に耐える橋を作る
  • Heat Lab限られた高伝導材で放熱路を作る
  • Crash Lab限られた材料で車を優しく止める
  • Magnet Lab鉄と磁石で磁束を導き、集め、遮る
  • Quantum Labゲートを並べてブロッホ球を目標の向きに

低レイヤーを読み解くツール

OS やハイパーバイザを書くときに、毎回引きたくなるものをブラウザに。

Page Table Visualizer

AArch64 と RISC-V（Sv32/39/48/57）のページテーブルを辿り、PTE をビット単位で解読。16進ダンプからメモリマッピングも解析できます。

MMUAArch64RISC-V

RISC-V Memory Model Viewer

LOAD / STORE / FENCE を複数 CPU に並べて、SC・TSO・簡略版 RVWMO で起こりうるグローバルオーダーを一覧。

メモリモデルRISC-V

RVRF — RISC-V Register Reference

RISC-V の CSR を名前やアドレスで検索し、値をビットフィールドごとに解読。Privileged ISA v1.13 準拠。

CSRRISC-V

Arm System Register Reference

AArch64 / AArch32 の 1700 以上のシステムレジスタを検索し、16進値をビットフィールドにデコード。

Armデコーダ
